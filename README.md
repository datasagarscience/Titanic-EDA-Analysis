# Titanic Dataset Exploratory Data Analysis (EDA)

This project contains an Exploratory Data Analysis (EDA) of the famous Titanic dataset using Python, Pandas, NumPy, and Seaborn. It is built as part of my portfolio to demonstrate foundational data manipulation and visualization skills.

##  Files in Repository
- `titanic.ipynb`: Jupyter Notebook containing the full end-to-end Python code and outputs.
- `tested.csv`: The dataset used for the analysis.

##  Libraries Used
- **Python**
- **Pandas** (for data cleaning and manipulation)
- **NumPy** (for mathematical operations)
- **Matplotlib & Seaborn** (for data visualization)

##  Key Steps & Analysis
1. **Data Loading & Inspection:** Loaded the dataset and examined its structure, data types, and shape.
2. **Handling Missing Values:** Handled missing values in columns like `Age` and `Fare` using median and mean imputation.
3. **Statistical Insights:** Computed basic statistics such as total passengers, survival count, average age, and maximum/minimum fare.
4. **Groupby Analysis:** Analyzed passenger survival counts based on passenger class (`Pclass`).
5. **Data Visualization:** Plotted survival rates by gender using Seaborn count plots.

##  How to Run
1. Clone the repository or download the files.
2. Open `titanic.ipynb` in Jupyter Notebook or VS Code.
3. Run all cells to view the analysis and charts.
